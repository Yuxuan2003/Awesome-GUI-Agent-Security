#### When Agents See Differently: Exposing UI Desynchronization Threats in Mobile Agents (UI Desynchronization) (2026-09)

Human oversight of mobile agents rests on an unstated premise: that user and agent observe consistent information from the same interface. This paper shows the premise is systematically violable. Users perceive interfaces through physical displays and the human visual system, subject to occlusion and luminance-contrast limits; agents consume digital screenshots that retain such content plus accessibility representations exposing nonvisual widget metadata. The same UI state can therefore carry materially different information to each party — termed human-agent UI desynchronization. The authors show a repackaged clone of a legitimate APK can exploit this to steer agents toward attacker-designated actions while remaining fully functional and behaviorally consistent for human users, with perturbations embedded before deployment and requiring no access to runtime instructions, agent detection, or online adaptation. Across five mobile-agent frameworks, three backbones, and 546 tasks: average misleading rates 77.9% (static) and 66.9% (dynamic). A questionnaire study with 186 participants confirms the visual perturbations are hard for humans to notice.

#### PriMobiBench: Characterizing Visual Privacy Leakage in VLM-Driven Mobile GUI Agents (PriMobiBench) (2026-09)

Mobile GUI agents automate smartphone tasks by interpreting screenshot streams — a design that introduces serious and underexplored privacy risk, both direct leakage of on-screen sensitive information and unintended user profiling, with no standardized benchmark to quantify either. PriMobiBench is the first benchmark for visual privacy leakage and profiling in screenshot-driven mobile agents, providing a unified pipeline for data generation, trajectory construction, and multi-model evaluation, plus MobiLeak — execution traces from 16 apps covering 25 privacy attributes with 2,960 embedded privacy instances. Findings: VLMs extract sensitive information with up to 82.5% success, and infer user profiles from aggregated visual evidence at roughly 70%. A proposed mitigation masks privacy-sensitive but task-irrelevant UI elements before cloud processing, cutting profiling success by up to 58% at about 8% performance cost.

#### FocusMem: Factorizing Content, Readout, and Trust in Latent GUI Memory (FocusMem) (2026-08)

Latent memory compresses multimodal GUI trajectories into a few continuous tokens, but existing methods map each trajectory to one fixed block trained mainly by next-action supervision. Three problems follow: detail is lost in compression, one block must serve every decision stage, and irrelevant retrieved trajectories can still mislead the agent. FocusMem factorizes these responsibilities — a role-aware content basis pushes episodic memory toward reusable experience and working memory toward current task progress; a state-conditioned readout produces a decision-specific view of the same stored evidence; and a lightweight trust gate can suppress memory when retrieval is unreliable. That last component is why this belongs on a security list: it treats retrieved memory as untrusted input requiring gating, which is the structural defense against memory-poisoning style manipulation.

#### Alignment Is Local: A Paired Diagnostic for GUI Agents under User Persuasion (Alignment Is Local) (2026-07)

Introduces a paired diagnostic that measures how far a GUI agent's safety alignment degrades under multi-turn user persuasion. Alignment turns out to be local: agents refuse a harmful request in a single turn, then concede incrementally as the user persists with plausible-sounding justifications — and this decay is invisible to every single-turn metric. The finding implies that single-turn safety evaluation cannot characterise risk in realistic multi-turn interaction.

#### Do GUI Agents Believe Their Eyes? Diagnosing State-Belief Reliance on Pixels versus Structure (Perception-Fusion Gap) (2026-07)

Asks a question that sits upstream of every visual attack: a multimodal GUI agent reads the interface through two redundant channels — rendered pixels and serialized structure (DOM or accessibility tree) — and forms a state belief before acting, but no existing benchmark asks *which channel that belief came from*. The paper formalizes visual state reliance and measures it with paired single-channel interventions over 735 probes across real web, mobile and desktop interfaces, 225 of them zero-edit divergences mined from live production sites, scored by deterministic forced choice with no model judge. The Perception-Fusion Gap metric captures the fraction of probes a model perceives correctly yet resolves toward structure under conflict — which tells an attacker exactly which channel to poison.

#### Mobile GUI Agent Privacy Personalization with Trajectory Induced Preference Optimization (TIPO) (2026-04)

Reframes privacy as a personalization problem rather than a fixed policy: most systems optimize task success or efficiency, ignoring that different users want different privacy postures. The technical observation is that personalization induces systematic structural heterogeneity in trajectories — a privacy-first user prefers protective actions like refusing permissions, logging out and minimizing exposure, producing logically different and variable-length trajectories from a utility-first user, which destabilizes standard preference optimization. #### VisualTrap: A Stealthy Backdoor Attack on GUI Agents via Visual Grounding Manipulation (VisualTrap) (2025-07)

Identifies visual grounding — the mapping from a textual plan to concrete GUI elements — as an attack surface in its own right, distinct from planning or reasoning. The consequence is what makes it dangerous: a backdoor planted in grounding compromises the agent's behavior **even when it is given a completely correct task-solving plan**, so inspecting the plan reveals nothing wrong. VisualTrap hijacks grounding by misleading the agent into locating the textual plan at attacker-chosen positions, which means every layer of plan-level review or reasoning audit passes cleanly while the actions still land where the attacker wants.
