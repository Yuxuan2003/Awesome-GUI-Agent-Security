#### SEAM: Computer-Use Agents Know the Harm Between Screens, and Commit It Anyway (SEAM) (2026-11)

CUA safety benchmarks place harm either in the task intent or on a single screen — a malicious instruction, an injected command, a phishing page — so an agent that checks the task and each screen in isolation can pass them. In delegated work, however, harm often arises by combination: a fact about a person on one screen, a fact about an item on another, and a legitimate task that binds them. SEAM (Safety Execution Across Multiple screens) contains 600 multi-step, cross-application OSWorld tasks in which the instruction and every single observation are benign and only their combination is harmful; minimal-pair variants scored from server logs rather than an LLM judge pinpoint where agents fail. General-purpose open-weight and flagship agents carry out the harm in up to 92% of runs yet decline when the user states it in one sentence; they open the decisive pages, flag the harm when asked, and with thinking often write the conflict into their reasoning and confirm anyway. Safety recognition does not reliably translate into safe execution, and the same warning stops agents far more often in the user's instruction than on screen; proprietary models are markedly more cautious.

#### OS-SPEAR: A Toolkit for the Safety, Performance, Efficiency, and Robustness Analysis of OS Agents (OS-SPEAR) (2026-04)

Diagnoses three concrete defects in current OS-agent benchmarks — narrow safety scenarios, noisy trajectory labeling, and limited robustness metrics — and answers with a four-dimension toolkit spanning Safety, Performance, Efficiency and Robustness. The subsets are separately constructed rather than reweighted from one pool: a Safety subset covering both environment-induced and human-induced hazards, a Performance subset curated via trajectory value estimation and stratified sampling, and an Efficiency subset measuring through dual lenses. Treating safety as one of four coupled axes rather than a standalone score is the framing worth borrowing.

#### LPS-Bench: Benchmarking Safety Awareness of Computer-Use Agents in Long-Horizon Planning under Benign and Adversarial Scenarios (LPS-Bench) (2026-02)

Identifies a timing gap in existing benchmarks: they focus on short-horizon or GUI-level tasks and score execution-time errors, but never test whether an agent can *anticipate* risk at planning time — before any action fires. LPS-Bench evaluates planning-time safety awareness of MCP-based CUAs on long-horizon tasks, covering benign and adversarial interaction across 65 scenarios spanning 7 task domains and 9 risk types, with a multi-agent generation pipeline and LLM-as-a-judge assessment over the planning trajectory. Existing CUAs show substantial deficiencies at maintaining safety awareness across long plans.

#### OS-Harm: A Benchmark for Measuring Safety of Computer Use Agents (OS-Harm) (2025-06)

Notes that CUA safety has been largely overlooked despite growing deployment, and introduces OS-Harm on top of the OSWorld environment to test three harm categories: deliberate user misuse, prompt injection attacks, and model misbehavior. It comprises 150 tasks spanning harassment, copyright infringement, disinformation, and data exfiltration, requiring interaction with email clients, code editors, and browsers. An automated judge scores both accuracy and safety with high human agreement (0.76 and 0.79 F1).

#### VPI-Bench: Visual Prompt Injection Attacks for Computer-Use Agents (VPI-Bench) (2025-06)

Notes that prior work concentrated on browser-based agents and HTML-level attacks, leaving CUAs — which hold full system access and can manipulate files, read user data and execute arbitrary commands — comparatively unexamined. VPI-Bench studies instructions embedded *visually* in rendered interfaces, which by construction bypass text-level sanitization, and supplies 306 test cases across five widely used platforms. Each case is an interactive variant of a real web platform deployed in a realistic environment with a visually embedded malicious prompt, covering both CUAs and browser-use agents.
